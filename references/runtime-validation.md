# Runtime
Use Chrome DevTools MCP já configurado no agente de IA; não instale um servidor nem SDK. Utilize as ferramentas disponíveis de navegação, redimensionamento/emulação e avaliação JavaScript; confirme nomes e argumentos pelo schema do MCP. Para localhost indisponível ou URL omitida, examine scripts do package.json da aplicação e README; solicite autorização para comando de inicialização (npm run dev, npm start, pnpm dev etc.). Não instale dependências. Aguarde disponibilidade com limite de tempo, confirme a rota e a identidade da aplicação. URLs publicadas são acessadas diretamente. Preserve sessões existentes e não encerre processos alheios. Não submeta formulários nem realize operações de negócio. Para telas autenticadas, use somente sessão autorizada. Ajuste viewport ao frame Figma, confirme dimensões CSS reais, fontes carregadas e estado estável. A função emitida por inspect-runtime.cjs é somente leitura, retorna objetos com IDs efêmeros, tags, papéis, classes, hierarquia, geometria, estilos e indicador booleano de texto direto; não retorna textContent, valores de campos ou HTML. Salve o retorno JSON real, sem wrappers. Limitações: DOM principal, não atravessa iframes ou shadow roots, não compara screenshots nem estados não visitados. Não force scroll ou interação sem necessidade e autorização. Se houver truncamento, registre cobertura parcial.

O schema 3 coleta pathname e color-scheme explícito do body (light/dark ou null). Não usa preferência do sistema como comprovação do tema aplicado. Confirme state, theme e interaction conforme validation-rules.md. A fonte efetiva permanece inconclusiva: a função de avaliação JavaScript não coleta fontes de plataforma por glifo.
