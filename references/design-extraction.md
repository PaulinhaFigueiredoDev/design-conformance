# Extração do design
Use somente REST API oficial: GET /v1/files/{key}/nodes?ids={id}, X-Figma-Token, escopo file_content:read. Aceita links figma.com/design ou /file com node-id. O script percorre os descendentes visíveis, agrupa vetores internos de ícones, mantém IDs, hierarquia, dimensões e posições de referência para calcular distâncias relativas, propriedades sólidas e regras explícitas de Auto Layout. Não exporta characters; nomes de camadas de texto são substituídos por identificadores neutros. Não infira margens CSS de coordenadas absolutas. Propriedades sem representação confiável (gradientes, efeitos, estilos mistos) ficam fora da comparação automática. O frame deve corresponder à tela e ao viewport que será inspecionado. Não trate valores de exemplo como requisitos.

O schema 3 inclui fileKey, frameId, specHash SHA-256 canônico das propriedades, hierarquia, dimensões e coordenadas relativas, rulesVersion e número de filhos visíveis que participam do layout antes de qualquer filtragem de vetores.
